# Краб-садовник — сайт с играбельной игрой

## Структура
```
index.html      — лендинг (разметка страницы)
css/style.css   — стили лендинга
js/script.js    — интерактивность лендинга + масштабирование игры
images/         — картинки лендинга (скриншоты, арт)

game/            — САМА ИГРА, полностью рабочая, открывается и отдельно
  index.html     — разметка игры
  style.css      — стили игры
  game.js        — логика игры
  img/           — сюда кладите спрайты игры (краб, водоросли, крюк и т.д.)
  music/         — сюда кладите bg.mp3 (фоновая музыка)
```

Игра встроена в раздел «Играть» на лендинге через `<iframe>` — это
специально сделано, чтобы стили и код игры и сайта не конфликтовали
между собой (у игры, например, свой сброс отступов и свои `id`).
Игру также можно открыть отдельно, просто запустив `game/index.html`.

## Как запустить
Просто откройте `index.html` в браузере — сайт не требует сборки,
сервера или установки зависимостей.

## Как вставить свои изображения
1. Положите файлы в папку `images/`.
2. В `index.html` найдите нужный тег `<img>` — рядом с каждым есть
   комментарий `ЗАМЕНИТЕ КАРТИНКУ` и понятное имя файла в `src`.
3. Замените имя файла в `src` на своё (например `images/hero-gameplay.jpg`
   → `images/moy-skrin.png`) — размеры и обрезка подстроятся автоматически
   через CSS.
4. Пока настоящей картинки нет — на её месте будет аккуратная
   заглушка с подписью, а не сломанная иконка браузера.

Список мест для картинок лендинга:
- `images/hero-gameplay.jpg` — скриншот/GIF геймплея в рамке в самом начале страницы.
- `images/about-crab-garden.jpg` — арт или скрин с крабом в разделе «Об игре».
- `images/screenshot-1.jpg` … `images/screenshot-6.jpg` — галерея в конце страницы.

## Как вставить картинки самой игры
Игра ссылается на файлы по именам, которые уже прописаны в её коде
(`game/index.html`, `game/style.css`, `game/game.js`). Просто положите
файлы с такими же именами в `game/img/`:
```
krab.png              — краб (игрок)
vodorosl'.png         — водоросль
urchin.png            — морской ёж
hook.png              — рыболовный крюк
kit.png               — кит
leaf.png              — иконка листика (счётчик)
background.png        — фон игровой сцены
sound-on.png / sound-off.png — иконка звука
shop.png              — иконка магазина
SHOP3.png             — фон окна магазина
speed.png, 2x.png, trim.png, shield.png, Boot.png — иконки бустов
boot.png              — ботинок, который «спасает» краба от крюка
```
и файл `game/music/bg.mp3` — фоновая музыка (кнопка звука в углу игры).

Без этих файлов игра всё равно полностью работает — краб двигается,
листики считаются, магазин и столкновения работают, — просто вместо
картинок будут пустые иконки, пока вы не добавите свои файлы.

## Играть без сайта
Игра — самостоятельный проект внутри `game/`, её можно открыть
и запустить в браузере отдельно от лендинга, просто открыв
`game/index.html`.
